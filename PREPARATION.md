# Lightspeed Restaurant Connector — Preparation

**Category:** C46. Restaurant / Hospitality Point-of-Sale (POS)  
**Vendor URL:** https://lightspeedhq.com/pos/restaurant  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Lightspeed Restaurant** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C46. Restaurant / Hospitality Point-of-Sale (POS)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **метрдотель** сталкивается с задачей: **автоматизация ресторанного зала, учет столов и курсов подачи, формирование кассовых чеков**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Lightspeed Restaurant переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **метрдотель, старший официант, менеджер смены**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `просмотр статуса столов зала -> открытие счета -> печать предварительного чека -> закрытие оплаты`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Lightspeed Restaurant.
